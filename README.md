# HackNova

## Contributing

- **Main always works**: The `main` branch must always remain in a working, deployable state.
- **One branch per module**: Work on dedicated branches named `feature/module-N-short-name`.
- **Small commits**: Make small, frequent commits using conventional prefixes (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).
- **Secrets**: Never commit secrets, passwords, private keys, or `.env` files.
- **Pull Requests**: All changes must be merged into `main` through Pull Requests after review.
